# Snippets

Paste-ready fragments for commands and small code patterns.

Use this area when the answer to the problem is a reusable fragment rather than a full script or reference guide.

- **Cheat sheet:** remember how something works.
- **Snippet:** copy/paste a fragment.
- **Script:** run a complete utility.
- **Runbook:** follow a safe procedure.
- **Template:** create a new artifact from a known-good starting point.

## Index

- [Bash](bash.md) — safe headers, loops, argument handling, temporary files, status capture.
- [Git](git.md) — inspect, branch, sync, compare, restore, search, stash.
- [jq](jq.md) — extract, filter, sort, transform, and pass shell values safely.
- [Networking](networking.md) — IP/routes, DNS, TCP tests, curl, TLS, SSH, tcpdump.
- [One-liners](one-liners.md) — high-frequency Linux administration commands.
- [PowerShell](powershell.md) — files, services, processes, networking, logs, JSON, secrets.
- [Text processing](text-processing.md) — grep, awk, sed, sort, cut, tr, strings.

Search from anywhere in the repo with:

```bash
ror find --type snippet <term>
```
